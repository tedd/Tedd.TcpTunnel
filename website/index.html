MAKE THE LINK FIT THE WORKLOAD

Small requests.
Large transfers.
Your choice.

01 /

A window you control

Send immediately, or collect data for a maximum number of milliseconds. A full buffer goes out without waiting for the deadline.

02 /

Compression with range

Choose Brotli, LZ4, Zstandard, Deflate, GZip, ZLib, or no compression. Brotli can retain history across frames to reuse repeated content.

03 /

More routes. One process.

Run independent forwarding setups with their own compression, connection limits, retries, socket settings, and packet captures.

START WITH YOUR PRIORITY

One command.
Room to tune.

Every setting is available in JSON and on the command line. Start with a profile, then adjust it for your traffic.

TERMINAL
tcptunnel --forward app --mode Client
  --listen-port 9000 --remote-host tunnel.example
  --remote-port 9001 --compression Lz4
  --batch-milliseconds 0 --socket:no-delay true

LZ4 with immediate forwarding and TCP_NODELAY. Run a matching Server on the other end.

Built for explicit control.

Updates stay in your hands. GitHub version checks offer an update. Downloads are verified against release checksums. Portable updates keep the previous binary; installed copies use an installer.

Keep the network boundary clear. TcpTunnel forwards and compresses traffic. It does not encrypt or authenticate the tunnel. Use a trusted network or an encrypted transport such as a VPN.
